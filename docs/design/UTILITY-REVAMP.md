# Utility page refresh

Arrow 2 generated the visual direction in the existing Quiver design chat. The exported source is `arrow-2-utility-concept.svg`; its isolated vector ornaments are `public/hidn-library-art.svg` and `public/hidn-utility-ribbon.svg`. The application keeps its Outfit font and existing theme tokens.

Payouts, the purchase library, Help, and purchase recovery share scoped utility styles. The signed-in home guide uses illustrative HTML cards with existing public example photography. Demonstration controls, including the grey Stop sales preview, are noninteractive.

Motion is limited to entry and hover effects, with reduced-motion overrides. Layouts stack on mobile. Payment eligibility, verification, ownership, and recovery API logic are unchanged.

Validation: TypeScript, production build, and all 75 automated tests passed. Local visual review covered Help and recovery in light and mobile blackout modes.
